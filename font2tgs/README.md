# font2tgs

Превращает буквы любого шрифта (TTF/OTF) в отдельные `.tgs`-файлы — формат
анимированных стикеров/эмодзи Telegram (Lottie JSON, сжатый gzip).

## Установка

```
pip install fonttools
```

## Использование

```
# Базовый вариант: русский + латинский алфавит + цифры, чёрный цвет, 100x100 (эмодзи)
python3 font2tgs.py MyFont.ttf

# Свои буквы, свой цвет, анимация появления
python3 font2tgs.py MyFont.ttf --chars "ПРИВЕТ" --color "#FF3366" --animate pop

# Стикеры 512x512
python3 font2tgs.py MyFont.ttf --size 512 --out stickers/

# С SVG-превью для быстрого просмотра
python3 font2tgs.py MyFont.ttf --svg
```

Опции:

| Опция | По умолчанию | Что делает |
|---|---|---|
| `--chars` | А–Я, A–Z, 0–9 | какие символы генерировать |
| `--color` | `1E1E1E` | цвет заливки, RRGGBB |
| `--size` | `100` | 100 = кастомные эмодзи, 512 = стикеры |
| `--margin` | `0.08` | отступ от края канваса |
| `--animate` | `none` | `pop` — появление с отскоком |
| `--out` | `tgs_out` | папка для результатов |
| `--svg` | выкл. | дополнительно писать SVG-превью |

Буквы масштабируются одинаково (по общему диапазону всех запрошенных символов),
поэтому «о» не раздувается до размеров «Ж», и все сидят на одной линии.

## Как загрузить в Telegram

1. Откройте [@Stickers](https://t.me/Stickers) в Telegram.
2. `/newemojipack` → **Animated emoji** (для эмодзи) или `/newanimated` (для стикеров).
3. Отправляйте `.tgs`-файлы по одному, каждому назначьте соответствующий эмодзи.
4. `/publish`, придумайте короткое имя — готово.

Кастомные эмодзи в сообщениях доступны подписчикам Telegram Premium;
создавать наборы может кто угодно.

## Требования Telegram, которые соблюдает скрипт

- канвас ровно 100×100 (эмодзи) или 512×512 (стикеры), 60 fps, длительность ≤ 3 с;
- gzip-сжатый Lottie JSON с полем `"tgs": 1`;
- размер файла ≤ 64 КБ (типичная буква занимает 300–800 байт);
- без выражений (expressions), растровых изображений, градиентов и масок.
